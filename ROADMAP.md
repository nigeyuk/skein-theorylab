# Roadmap

- **Phase 00 · Foundation.** Application shell, dashboard, navigation, module boundaries, shared keyboard preview and development checks.
- **Phase 01 · Music theory core.** Implement pitch and spelling, intervals, scales and key signatures, chords, introductory harmony and structured explanations. Verify the core independently.
- **Phase 02 · Virtual keyboard, audio and interactive theory.** Deliver the shared playable keyboard, Web Audio engine, basic physical MIDI input, application version display, and interactive Intervals and Chords workspaces.
- **Phase 02A · Sample-based instruments.** Add the acoustic grand, instrument selection and loading, velocity layers, safe polyphony, and synth fallback.
- **Phase 03A · Content Engine and Content Manager.** Deliver the IndexedDB library, metadata editing, safe viewers, and validated `.mytheorypack` import, export and library recovery. Preserve stable resource IDs for later learning progress integration.
- **Phase 03B · Multi-user platform (planned).** Evaluate PostgreSQL and Supabase. Design and verify authentication, server-enforced role and ownership policies, private libraries, shared published content, progress synchronisation, and account data export and deletion.
- **Phase 04 · Interactive reference library.** Build the full interactive reference experience on the validated content catalogue, using bundled and user-imported resources, including Musical Fundamentals.
- **Structured curricula (planned).** Extend the Content Engine and a future `.mytheorypack` contract with pathway, course, module and lesson definitions. Connect progression and assessment evidence through the Learning Engine. Integrate notation-based assessments when the notation editor Learning-mode interface is available. [Curriculum architecture](CURRICULUM.md)
- **Phase 05 · Standalone notation editor integration.** Audit both repositories before implementation. Compare shared dependencies and public interfaces, identify duplicate functionality and integration blockers, then embed the existing editor with Learning and Studio configurations while preserving standalone operation. Extend the content schemas for validated score resources and exercises.
- **Later phases.** Build advanced counterpoint and composition on the integrated score editor. Expand visualisations, exercises and progress based on recorded activity. Add more instrument sounds, playback examples, advanced MIDI mapping and deeper hardware integration.
